# 片尾关注卡（end-card-cta）

**一句话**：3 秒方形（1:1）片尾关注卡——外圈细圆弧描出、实心按钮与加号弹入、品牌名上浮、胶囊 CTA 回弹落下，收尾段彗星光点持续公转、按钮呼吸、CTA 周期泛光，透明背景，适合视频结尾的关注/订阅引导。

## 画面与节奏

0–0.7 s 外圈细圆弧顺时针描出（圆头细线）→ 0.55 s 实心圆按钮与加号依次弹入 → 0.45–1.15 s 品牌名上浮淡入 → 0.95–1.40 s 胶囊 CTA 回弹落下 → 1.6–2.3 s 斜向微光首次扫过主体；1.2 s 起彗星光点沿环公转、1.5 s 起关注钮轻微呼吸、2.3 s 起 CTA 周期泛光，停留段保持动感直至 3 s。

## 可改内容

- `brand` 品牌/账号名：1–12 字，建议 2–8 字
- `cta` 关注引导语：1–16 字，建议 6–12 字（关注我，更新不错过 / 订阅频道看下期）
- `theme` 主题：极简白（默认，亮暗背景通用）/ 霓虹夜（暗背景）/ 暖橙
- 预设：默认、霓虹、暖橙

## 适合 / 不适合

- 适合：Vlog、口播、教程、测评、知识视频结尾的关注与订阅引导；系列节目统一的片尾账号名片；方形/竖屏短视频结尾的品牌名＋一句行动号召；也可叠到横屏片尾留白区
- 不适合：片头开场或章节片名；竖屏全屏人物姓名卡；二维码、头像、Logo 图片位或多链接菜单；大段免责声明

## 已知限制

- 只承载圆环、文字与一个按钮，不支持二维码/图片位
- 版本只增不覆盖：后续改动走 1.1.1 patch
