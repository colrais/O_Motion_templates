# 海边电影感·竖屏

竖屏旅拍短片模板：海边空镜、字幕卡、配乐与节奏按分镜排布，配音走 TTS + 词边界对齐。当前**暂不公开发布**，仅作登记。

| 状态 | 本地留存（`shelved`），暂不公开 |

---

## 特点

- 10 段分镜：空镜 → 字幕卡 → 人物 → 收尾，元素与动效按段落编排
- 配音链路：分段 TTS → ASR 二次对齐词边界 → 音效与卡点混音
- 竖屏构图，适配旅拍、探店、人物短片
