# 线稿故事（line-story）

**一句话**：把你手里已有的内容——一段流程、一篇文章、一天的生活记录、一个想讲的道理——变成一支金线逐笔生长的线描故事短片；画到哪里，旁白就说到哪里。

## 画面与节奏

暗底金色细线逐笔生长，画完一笔接下一笔；一幕画完「抬笔」，旧幕淡出，一颗光点飞向下一处空间再落笔。默认示例是普通人的一天：闹钟、窗与街、桌与屏、一碗面、回家的灯、床与月亮，约半分钟。旁白、字幕与画面同源驱动，不会各说各话。

## 可改内容

- **场景数量与顺序**：想画三幕就三幕、十幕就十幕，成片时长随之变化
- **每笔画什么**：生活物件、流程节点、抽象关系都能画，按你给的位置与时间落笔
- **旁白文案与出场时机**：一句一幕，字幕自动跟随旁白时间
- **主色、辅色、底色**：换成你片子的色调（风格靠「暗底＋亮线」成立，别换成亮底）
- **标题文字**：文案与出现时机可改
- **配乐与环境声**：音量可调，旁白说话时自动压低
- **字幕**：可留在画面内，也可另导出 SRT 自行压制

## 适合 / 不适合

- 适合：知识解释、流程说明、品牌故事、课程章节、个人日常叙事；需要「有人愿意看完」的说明型短片
- 不适合：需要直播质感的口播原片、需要实拍素材混剪的片子，以及要求精确卡点的商业广告（画面由内容驱动，不按固定分镜）

## 已知限制

- 内容驱动、无固定镜头时长，逐帧对齐的甲方脚本需要先转成幕次与旁白
- 单人旁白统一音色；多角色对白不在本模板
- 版本只增不覆盖：后续改动走 patch 位
