# 卡通涂鸦片头（cartoon-scribble-open）

**一句话**：5 秒横屏卡通手绘风片头——黄色涂鸦笔刷色块自左生长，主标题逐字彩色弹入，配四件手绘装饰与程序音效，输出透明背景，可直接叠到视频开头。

## 画面与节奏

0–0.55 s 黄色笔刷自左生长 → 0.6–1.65 s 主标题 2–6 字逐字彩色弹入（贴纸式双层描边、手写扰动）→ 1.95 s 闪光 → 2.15 s 铃音与叶枝 → 结尾整体淡出。装饰为枫叶、蝴蝶、相机、叶枝四件手绘元素；音效为 whoosh、逐字 pop、闪光 ting、叶枝叮铃，按镜头锚点混入。

## 可改内容

- `title` 主标题：2–6 字最佳，最长 6 字
- `subtitle` 副标题：一行小字，最长 20 字，可留空
- `titleColors` 逐字配色：2–6 个 `#RRGGBB`，从左到右循环
- 预设：默认 / 糖果色 / 薄荷天空

## 适合 / 不适合

- 适合：Vlog、生活、亲子、手账、校园类活泼片头；固定栏目片头只换标题
- 不适合：严肃商务、科技发布、国风文史开场；竖屏全屏模板；承载多段正文或旁白

## 已知限制

- 固定 5 秒：剪辑缺口更短时由剪辑软件加速或裁切尾部定格，模板不改时长
- 固定横屏：不提供竖屏版本
