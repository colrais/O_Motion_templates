# 点阵肖像（DotMatrix Portrait）

三张人像依次化为流动的双色点阵，散开后重新汇聚成标题的 13 秒横屏开场，适合人物系列片头、活动开场、作品集扉页。

| 项 | 值 |
|---|---|
| 模板 id | `dotmatrix-portrait-v1` |
| 版本 | v1.0.0 |
| 运行时 | `html-canvas/1` |
| 画幅 / 帧率 / 时长 | 1920×1080 / 30 fps / 13 s（默认） |
| 许可 | MIT |
| 网络依赖 | 无（点阵、粒子、字体全部本地计算） |
| 状态 | 审核中（MotionGit） |
| 确定性 | 固定随机种子，同一参数 + 同一时间点多次渲染哈希一致 |

---

## 画面结构

| 时间段 | 内容 |
|---|---|
| 0 – 3.6 s | 第一张人像按点阵显影，暖金配色（主色 `#E3A86F` / 暗部 `#5A3A28`） |
| 3.6 – 6.0 s | 切换第二张人像，青蓝配色（`#4FB7C9` / `#173C46`） |
| 6.0 – 9.2 s | 切换第三张人像，红橙配色（`#E8604C` / `#4A201C`） |
| 9.2 – 10.8 s | 点阵散开成粒子云 |
| 10.8 – 12.2 s | 粒子汇聚成中文标题的点阵轮廓 |
| 12.2 – 13.0 s | 标题与英文副标题落定、静止收尾 |

## 可改参数

参数契约文件：`params.schema.json`（打包在模板内）

| 参数 | 类型 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| `titleZh` | string | 最长 12 字 | `点的轮廓` | 结尾汇聚的中文主标题（必填）；建议 2–6 字 |
| `titleEn` | string | 最长 40 字符 | `OUTLINE OF DOTS` | 中文标题下方的英文小字 |
| `portrait1` | 图片路径 | — | 程序化占位轮廓 | 第一段人像（暖金） |
| `portrait2` | 图片路径 | — | 程序化占位轮廓 | 第二段人像（青蓝） |
| `portrait3` | 图片路径 | — | 程序化占位轮廓 | 第三段人像（红橙） |
| `mainColor1` / `darkColor1` | 颜色 | — | `#E3A86F` / `#5A3A28` | 第一段配色 |
| `mainColor2` / `darkColor2` | 颜色 | — | `#4FB7C9` / `#173C46` | 第二段配色 |
| `mainColor3` / `darkColor3` | 颜色 | — | `#E8604C` / `#4A201C` | 第三段配色 |
| `dotSpacing` | number | 4 – 20 | 9 | 点阵间距（px），越小越密；6–12 为宜 |
| `dotRadiusMin` | number | 0 – 4 | 0.8 | 最小点半径 |
| `dotRadiusMax` | number | 1 – 10 | 4.6 | 最大点半径 |
| `duration` | number | 8 – 30 | 13 | 总时长（秒） |
| `tP1End` | number | ≥ 0 | 3.6 | 第一段人像结束时间点 |
| `tP2End` | number | ≥ 0 | 6.0 | 第二段人像结束时间点 |
| `tP3End` | number | ≥ 0 | 9.2 | 第三段人像结束时间点 |
| `tScatterEnd` | number | ≥ 0 | 10.8 | 散开结束时间点 |
| `tTitleEnd` | number | ≥ 0 | 12.2 | 标题汇聚完成时间点 |

## 使用建议

- **人像选材**：主体居中、背景干净的半身或头肩像效果最好；三张同一位人物可做「同人三风格」，三张不同人物可做「人物群像开场」
- **配色情绪**：三段配色建议做一次情绪递进（暖 → 冷 → 强），全部同色系会削弱段落感
- **标题长度**：中文 2–6 字最稳；超过安全宽度（画布宽 72%）时字号会自动缩小，字太多会明显变轻
- **与音乐对齐**：三个切换点就是三个卡点，改时间点等于改节奏，按 BGM 落点调

## 已知限制

- 未提供人像时会使用程序化生成的占位轮廓（可正常出片，但不是成品效果）
- 时长与各阶段时间点是**绝对时间轴**：改 `duration` 不会自动重排时间点，需要同步调整 `tP1End`…`tTitleEnd`
- 不做自动循环播放；需要循环请在成片侧处理
- 只支持横屏（`layout = landscape`）
